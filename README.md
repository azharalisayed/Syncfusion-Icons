# Syncfusion Icons Explorer

A fast, modern, and developer-friendly icon browser built for exploring Syncfusion icon classes with ease.

This project helps developers quickly search, preview, and copy Syncfusion icon names for use in web applications powered by Syncfusion UI components.

🌐 Live Demo: https://azharalisayed.github.io/Syncfusion-Icons/

---

## ✨ Features

- 🔍 Instant icon search
- 📋 One-click copy to clipboard
- 🎨 Live icon preview
- ⚡ Lightweight and fast interface
- 📱 Fully responsive design
- 🧩 Compatible with Syncfusion UI libraries
- 🌙 Clean and modern developer experience

---

## 🚀 Purpose

Working with large icon collections can slow down development when searching through documentation manually. This project provides a simple visual explorer that improves productivity and makes icon discovery faster and easier.

Developers can:

- Search icons instantly
- Preview icons before use
- Copy icon class names directly
- Speed up UI development workflow

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/azharalisayed/Syncfusion-Icons.git
cd Syncfusion-Icons
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
